# GRID DODGE

3x3 のマスを1マスずつ動いて、レーザーと隕石を避けるゲーム。ブラウザで動く。
[web-game-template](https://github.com/pupe-xxx/web-game-template) から作った（TypeScript + Vite + Canvas、ゲームエンジンなし）。

## 遊び方

- スマホはフリック、パソコンは矢印キーか WASD で1マス動く
- 赤く光ったマスは、枠が真ん中まで縮んだ時に撃たれる。それまでに光っていないマスへ逃げる
- 1回当たったら終わり。生き残った時間が点数になる

## ルール

- 障害は3種類：横1行のレーザー、縦1列のレーザー、1マスの隕石
- 波ごとに、今いるマスが必ず撃たれる（動かないと当たる）
- 安全なマスは、今いるマスから動ける範囲（予告が長い間は2マス、短くなると1マス）に必ず残る
- 前の波を撃ち終わってから、次の波の予告が出る
- 進むほど予告が短くなり（1.1 秒 → 0.4 秒）、同時に来る数が増える（1 → 4）

数値は `src/game/rules.ts` の `waveTiming`・`hazardCount`・`reachOf` にある。

## 立体版（3x3x3）

ルールだけ入っている。`src/game/rules.ts` の `CUBE` を渡すと、奥行きのある盤で同じルールが動く（障害は3方向の列、移動は6方向）。
画面なしの自動プレイ・テスト・動作記録は立体版も対象にしている。
画面と操作はまだ無い。視点と、奥行き方向の動かし方を決めてから作る。

## コマンド

| コマンド | すること |
|---|---|
| `npm run dev` | 手元で動かす（保存すると画面がすぐ変わる） |
| `npm test` | ルールの自動テスト |
| `npm run sim -- 1000 1 180` | 画面なしで自動プレイを 1000 回走らせ、180 秒避け切れた回数を出す（平面と立体） |
| `npm run record` | 動作記録（`tests/golden/golden.json`）を取り直す |
| `npm run typecheck` | 型の検査（ルール側が画面に触れていないかも見る） |
| `npm run build` | 検査してから `dist/` に公開用のファイルを作る |
| `npm run preview` | `dist/` の中身を手元で開く |

## フォルダ

```
src/
  main.ts    入口。操作を溜めて、1刻みごとにルールへ渡す
  kit/       型から来た共通部分（乱数・画面サイズ・音・セーブ・毎フレーム進める仕組み・広告の差し込み口）
  game/      ルール。画面の処理に触れない
    rules.ts   盤・障害・波の作り方・1刻み進める処理
    bot.ts     自動プレイ（予告されたら、いちばん近い安全なマスへ寄る）
    sim.ts     画面なしで遊ばせる
  ui/        描画
tests/       ルールと共通部分のテスト
  golden/      動作記録（golden.json）と、記録する場面（cases.ts）
scripts/     画面なしの自動プレイ、動作記録の取り直し
```

## 守ること

- **`src/game` は画面に触れない。** `document`・Canvas を使うと `npm run typecheck` がエラーになる
- **ルール側で `Math.random` と時計を使わない。** 乱数は `kit/rng.ts` を引数で受け取り、時間は刻みの回数で数える。同じ種と同じ操作なら同じ結果になる
- **波の作り方を変えたら `npm run sim` を走らせる。** 自動プレイが避け切れない回があれば、避けられない波が出ている
- **ルールを意図して変えたら、動作記録を取り直す（`npm run record`）。** 取り直す前に「変わってよい理由」を確かめる
- **描画は論理サイズの座標で書く。** 画面の実寸や `devicePixelRatio` を描画のコードに持ち込まない
- **広告・計測は `kit/platform` の形を通して呼ぶ。** ゲーム本体に SDK を直接書かない

## 公開

`main` に push すると、テスト → ビルド → 公開まで自動で進む（`.github/workflows/pages.yml`）。テストかビルドが失敗したら公開されない。
共通部分（`src/kit`）は型のコピーで、型を直してもここには自動では届かない。
